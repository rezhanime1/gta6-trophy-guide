Vice Trophy Guide — a GTA 6 trophy guide and tracker built for the [make.fun gta6-trophy-guide-01 bounty](https://make.fun/bounty/gta6-trophy-guide-01).

All 55 GTA VI PS5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze) with their official names and descriptions, a per-trophy guide in plain words, an 8-stage platinum roadmap, and a tracker: checklist saved in the browser, filters by grade/status/missable, search, a spoiler setting, and export/import of progress.

Run it with `node serve.ts` (http://localhost:8080), or build with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
